## Notes for S7 and the orchestrator

- `demo.sh offline` in both examples fetches kubeconform schemas from GitHub (`yannh/kubernetes-json-schema`, `datreeio/CRDs-catalog`) on the first run; it needs network.
- `scripts/install-tools.sh` installs plugins with `--verify=false`; chapter 13 says so and links the plugin docs.
- `.github/ct.yaml` is a new file owned by S6.3 (CI config). It excludes `pc-lib` and turns off `check-version-increment` and `validate-maintainers`.
- `helm dependency build` and `ct lint` rewrote the gitignored `charts/*/charts/*.tgz` archives in `charts/`; contents are rebuilt from the same sources.
- The snapshot file `tests/__snapshot__/snapshot_test.yaml.snap` embeds `helm.sh/chart: shipping-service-0.14.0`; a version bump in the snapshot chart needs `helm unittest -u`.
- No golden chart bugs found. `ct install` on `charts/shipping-service` (version 1.0.0) is not exercised by the example, which uses its own 0.14.0 snapshot.
