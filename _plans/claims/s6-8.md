## Golden chart bug (not fixed)

`charts/shipping-platform/templates/route.yaml` renders a notification Route, and `templates/tests/test-connection.yaml` probes `platform-notification`, even when `tags.messaging=false`. The minimal profile (no operators, no Kafka) then has a dangling Route and a failing `helm test`. The example copy in `examples/27-openshift-crc/charts/shipping-platform/` gates both on `.Values.tags.messaging` (and adds a trailing comma so the single-URL Python tuple still iterates URLs). Recommend porting the fix to `charts/` and its unit tests (`route_test.yaml` has no case for messaging off).
