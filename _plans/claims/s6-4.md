## Golden-chart notes (not fixed here)

- `charts/starters/pc-fastapi`: `tests.image` defaults to `registry.access.redhat.com/ubi10/ubi-minimal:latest` and the test pod runs `curl`; ubi-minimal has no numeric USER so `runAsNonRoot` fails on a cluster (see s5 notes). The schema also requires `tests.image` `minLength: 1`, which blocks the empty-string fix. The ch18 snapshot carries the fix (Python probe from the chart image, `tests.image: ""`, schema without `minLength`); the golden starter should adopt it.
- `charts/starters/pc-fastapi/README.md` line 10 starts a prose line with `helm create`, which `scripts/check-helm-commands.sh` flags; the ch18 snapshot rewords it. The golden file (under `charts/`) would trip the same check if the script ever scans it.
- The starter has no `tests/` helm-unittest suite, unlike the other app charts.
- `shipping-kafka/values.yaml` comment says "Strimzi 0.51+ serves v1" while CONTRIBUTING.md pins Strimzi 0.51.0 and `setup-kafka-operator.sh` defaults to 1.2.0; chapter 15 states 1.2.0.
