What this tutorial is

A chapter-based path through Helm 4 for application developers. One fixed Python 3.15 / FastAPI application, a shipping service that publishes events to a notification service through Kafka and stores its data in Postgres, goes from raw manifests to a chart, an umbrella chart, a library chart, a signed OCI artifact and an Argo CD deployment. The application image never changes between chapters; only the charts and values do, so each chapter stays focused on Helm. Everything runs on a dedicated minikube profile with CloudNativePG, Strimzi and the Grafana LGTM stack. An appendix repeats the deployment on OpenShift Local. The tutorial assumes you can read Kubernetes manifests and write a Dockerfile; it does not teach Python or Kubernetes basics.
